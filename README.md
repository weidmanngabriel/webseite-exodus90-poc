# Exodus 90 Website POC

Schlanker Proof of Concept für einen technischen und visuellen Relaunch von Exodus90.de.

## Ziel

Die bestehende Informationsarchitektur und die wesentlichen Inhalte/Funktionen werden als einfache, wartbare statische Website neu gedacht. Der POC soll zeigen, dass der aktuelle Funktionsumfang ohne schwergewichtige technische Architektur umgesetzt werden kann.

## Technologie

- HTML5
- CSS3
- Vanilla JavaScript
- kein Framework
- kein Build-Schritt
- GitHub-Pages-kompatibel

## Umfang des POC

- responsive Navigation
- Hero und Inhaltssektionen
- Programm-/Prinzipienübersicht
- Ablaufdarstellung
- Gruppenbereich mit Karten-Platzhalter
- Erfahrungsberichte
- Download-Teaser
- FAQ-Accordion
- Newsletter- und Kontaktformular als UI-Prototyp
- responsiver Footer

Nicht Teil des POC sind die echte Kartenintegration, Backend-Verarbeitung von Formularen, CMS und externe Integrationen.

## Lokaler Start

`index.html` direkt im Browser öffnen oder einen beliebigen statischen Webserver verwenden.
